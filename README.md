## Installing 
Flask app
- cd flask_app
- pip install -r requirements.txt
- add .env considering .env.example
- add IoT.crt files in flask_app directory
- python3 app.py
- Swagger: http://localhost:5000/api/docs/

React app
- cd react_app
- npm i
- npm start
- UI: http://localhost:3000
